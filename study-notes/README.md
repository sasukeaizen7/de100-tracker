# Study notes

My notes for the 100-day data engineering program, one file per course, in program order.

Each file follows the course's sections. For every concept: a short explanation, a runnable example, common mistakes, and interview questions. Under each section, **My notes** is for what I learn while watching (commands that tripped me up, screenshots, links).

| Days | Course | Notes |
| --- | --- | --- |
| 1–9 | The Complete SQL Bootcamp (Jose Portilla) | [sql/01-complete-sql-bootcamp.md](sql/01-complete-sql-bootcamp.md) — run [sql/setup.sql](sql/setup.sql) first |
| 10–13 | Data Engineering Project SQL, Python, Airflow, Docker, CI/CD (Matthew Schembri) | [02-python-data-eng.md](02-python-data-eng.md) |

## How to use these notes

1. Read the section's notes before watching that section (10 minutes).
2. Watch, coding along in your own repo instead of copying the instructor's.
3. Fill in **My notes**. Write what surprised you, in your own words.
4. Answer the interview questions out loud, in French and in English.
